# F1. Report residue by call

**Status:** todo

## Spec
As a farmer, I describe my residue by phone in Urdu so someone comes to collect it.

**Build:** the call reaches the ADK voice agent through Twilio, or through the browser widget as a fallback. The agent calls a create\_lot tool (residue type, quantity, pickup window, and village and district matched to coordinates from a seeded list), and the API saves the lot.

## Acceptance criteria
- Done when: a spoken call produces a complete lot in Firestore and the agent reads the details back.
