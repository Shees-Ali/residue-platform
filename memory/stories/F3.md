# F3. Reach a person when stuck

**Status:** built (tried live on /phone 2026-10-16)

## Spec
As a farmer, I can ask for a person when the agent can't help.

**Build:** an escalate\_to\_human tool saves the transcript and a summary to an escalations collection, which shows in the admin queue.
