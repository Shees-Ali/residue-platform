# T1. Find and accept a job

**Status:** backend done (transporter UI todo)

## Spec
As a transporter, I see jobs offered to me with pickup place, estimated weight, destination and pay, and accept before the offer expires.

**Build:** each offer has an expiry. The dashboard listens to offers addressed to me, shows pickup and factory pins on a Leaflet map, and accepting runs as a Firestore transaction so only one transporter wins.

## Acceptance criteria
- Done when: two simultaneous accepts produce one winner and the other sees the offer withdrawn.
