# A2. Watch jobs and handle escalations

**Status:** backend done (admin UI and live events UI todo)

## Spec
As an admin, I follow every job live, handle escalations and approve transporters.

**Build:** Firestore listeners drive the job list and escalation queue. Approving a transporter sets a tier that controls job size. The tick endpoint, or a demo fast-forward button, expires unanswered offers and moves to the next transporter.

## Acceptance criteria
- Done when: an unanswered offer moves to the next transporter without anyone clicking.
