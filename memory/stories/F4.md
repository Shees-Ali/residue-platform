# F4. Confirm delivery and payment

**Status:** code complete (outbound dial via Telnyx); not yet tried on a live call

## Spec
As a farmer, I confirm the weight and the amount I will receive, so I know I was paid fairly.

**Build:** after the factory confirms, the agent places a verification call through Telnyx (was Twilio; in the demo, a button starts it) and records a yes or a dispute.

## Acceptance criteria
- Done when: a yes completes verification and releases the payout, and a dispute freezes it and alerts the admin.
