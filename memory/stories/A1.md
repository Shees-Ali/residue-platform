# A1. Assign the factory

**Status:** backend done (admin UI todo)

## Spec
As an admin, I want each lot matched to the best factory automatically, with the option to override.

**Build:** the API scores factories by residue type accepted, distance (haversine in code) and price. The admin screen shows the ranked list, and overrides are logged.
